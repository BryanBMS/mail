# Mail-bestanden

Openbare bestanden voor e-mails, gehost via GitHub Pages.

## siveo/
Bestanden voor de maandmail van S.V. Siveo '60.

- `logo.png`: clublogo
- `icons/`: iconen in blauw, geel en wit (`naam-kleur.png`)
- `*.ics`: agendabestanden voor activiteiten

Basisadres: https://bryanbms.github.io/mail/siveo/

Let op: deze repository is openbaar. Zet hier alleen afbeeldingen en agendabestanden neer, geen mails, ledenlijsten of andere persoonsgegevens.
